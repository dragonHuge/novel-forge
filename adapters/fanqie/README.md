# 番茄小说 Adapter

## 数据收集方式

**v0.1.0**: 手动模式 — 用户从番茄作者后台复制数据，口述或贴入对话。

**计划中**: 浏览器自动化（CDP / Playwright）自动抓取作者后台数据。

## 可收集指标

| 指标 | 来源 | 短篇 | 连载 |
|------|------|------|------|
| 签约状态 | 作品管理页 | ✓ | ✓ |
| 收藏数 | 数据概览 | ✓ | ✓ |
| 阅读量 | 数据概览 | ✓ | ✓ |
| 收入 | 收入明细 | ✓ | ✓ |
| 追更率 | 粉丝数据 | — | ✓ |
| 推荐票 | 数据概览 | — | ✓ |
| 编辑反馈 | 消息/通知 | ✓ | ✓ |

## 收入档位定义

| 档位 | 月收入（元） |
|------|-------------|
| S | >5000 |
| A | 2000-5000 |
| B | 500-2000 |
| C | 100-500 |
| D | <100 |

## 复盘窗口

- 短篇：T+7 天（签约审核 3-5 天 + 初始数据）
- 连载：T+30 天（追更趋势需要更长观察期）
