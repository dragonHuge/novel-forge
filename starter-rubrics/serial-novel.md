# 连载小说评分卡（Starter Rubric）

> 适用品类：中篇（3-15 万）、长篇（15-50 万）、超长篇（50-200 万）
> 平台：番茄小说（连载日更模式）

## 7 维度评分（每项 1-5 分，满分 35）

| 维度 | 评分标准 | 权重说明 |
|------|----------|---------|
| **标题点击感** | 信息流/书架中是否一眼抓住？题材+卖点是否 3 秒可识别？ | 高 |
| **开局炸裂度** | 前 3 章（约 9000 字）能否建立核心冲突？追读动力是否足够？ | 关键（决定签约和推荐） |
| **情绪强度** | 核心冲突的持续张力？读者能否持续为主角命运揪心/爽快？ | 高 |
| **反转空间** | 长线伏笔布局？每卷是否有独立高潮 + 跨卷悬念？ | 高 |
| **追更粘性** | 每章结尾是否有钩子？日更断点设计是否让人"明天还来"？ | 关键（直接影响追更率） |
| **独特性** | 与同品类连载的差异化？世界观/人设/叙事结构有无创新？ | 关键 |
| **题材匹配度** | 是否有对应题材方法论支撑？长线节奏控制是否有章法？ | 中 |

## 判断标准

| 总分 | 判断 | 动作 |
|------|------|------|
| ≥30 | 强题 | 立刻立项，优先排日更 |
| 25-29 | 可做 | 立项，但先完成大纲全卷规划再动笔 |
| 20-24 | 存灵感 | 世界观/人设有潜力但结构不够，存灵感池 |
| <20 | 放弃 | 长篇投入大，弱题不值得 |

## 连载特有注意

- 第三人称为主，长短句自然交错
- 每章 3000 字左右，信息密度适中
- 克制叙事：不煽情、不排比堆情绪，用动作和细节传递情感
- 每卷有完整弧光（开 → 升 → 爆 → 悬念钩下一卷）
- 超长篇需要伏笔追踪表 + 角色状态快照
