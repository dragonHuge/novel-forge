# novel-seed — 选题讨论

> 触发词："找选题"/"我想写一个 X"/"最近有个想法"/"seed"/"有个创意"

## 工作模式

**默认模式（一次一个）**：用户主动给一个主题/经历/灵感碎片，AI 围绕输入深挖：

1. 提炼核心冲突（一句话说清"这个故事的 hook 是什么"）
2. 挖掘情绪锚点（读者为什么会代入？爽在哪？）
3. 设计反转空间（至少 2 层反转草案）
4. 给出品类建议（超短/中短/中篇/长篇）
5. 输出一份**创意卡**写入 candidates.md

**Batch 模式**（`/seed --batch 5`）：一次 brainstorm 5 个创意，每个一句话 + 粗评分，用户择优深挖。

## 创意卡格式

```markdown
### {创意标题}（{品类}）
- **核心 hook**: {一句话}
- **情绪锚点**: {读者为什么代入}
- **反转草案**: {2 层}
- **粗评分**: {X}/35（快速估算，不精确打分）
- **状态**: 待深挖 / 可立项 / 已放弃
```

## 规则

- 不主动推选题——等用户给输入再深挖
- 如果 candidates.md 不存在，先创建
- 不做精确 7 维打分（那是 /score 的事）
- 如果创意明显 <20 分水平，直说"这个方向比较弱"并解释为什么
