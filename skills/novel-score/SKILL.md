# novel-score — 轻量 7 维打分

> **纯输出，零副作用**。不写任何文件，不修改 state，不创建预测日志。
>
> 定位：预测之前的快筛工具——30 秒内告诉用户"这个创意几分、薄弱点在哪"。

---

## 触发条件

用户说以下任一时路由到本 skill：

- "打分"/ "score" / "给这个创意打分" / "先打分看看" / "评估一下"
- "这个想法怎么样"（含"想法"/"创意"/"题材" + 评价意图）

## 前置条件

1. `.novel-state.json` 存在 → 否则路由到 `/novel-init`
2. 用户提供了评分对象（文件路径 **或** 口头描述）→ 否则反问

## 输入方式

接受两种输入：

1. **文件路径**：指向 `novels/<book-slug>/outline.md`、创作设定.md、或任意含故事梗概的文件
2. **口头描述**：用户在对话中直接描述创意（标题 + 题材 + 卖点 + 梗概）

如果用户只说"打分"没给目标 → 回复：
> 打分哪个？给我创意描述，或者告诉我创作设定的文件路径。

---

## 执行流程

### Step 1: 加载评分标准

1. 判断品类：
   - 用户明确说了"短篇" / 文件 meta.json 标注字数 < 8 万 → 加载 `starter-rubrics/short-story.md`
   - 否则 → 加载 `starter-rubrics/serial-novel.md`
   - 判断不了 → 问用户"这是短篇完本还是连载？"

2. 检查 `rubric_notes.md` 是否存在：
   - 存在 → **优先使用** rubric_notes.md 中的维度定义和权重（用户进化版覆盖 starter）
   - 不存在 → 使用 starter-rubrics 原始版

### Step 2: 评分

对 7 个维度逐一评分（1-5 分），每个维度给出：
- 分数
- 一句话理由（为什么是这个分，不是更高/更低）

评分原则：
- **严格基于提供的信息**——信息不足的维度打 2-3 分（不确定≠高分）
- **不脑补**——用户没说的不替用户想象"应该能做到"
- **对标基线**：3 分 = 同品类中位水平，5 分 = 同品类 Top 5% 水平
- **独立评分**：每个维度独立判断，不因整体印象拉高/拉低

### Step 3: 输出

格式严格如下：

```
## 打分结果：《{标题或创意简称}》

品类：{短篇/连载} | 题材：{题材标签} | Rubric：{starter / vN}

| 维度 | 分数 | 理由 |
|------|------|------|
| 标题点击感 | X/5 | ... |
| 开局炸裂度 | X/5 | ... |
| 情绪强度 | X/5 | ... |
| 反转空间 | X/5 | ... |
| {第5维度} | X/5 | ... |
| 独特性 | X/5 | ... |
| 题材匹配度 | X/5 | ... |

**总分：{N}/35 → {判断}**

### 薄弱维度诊断

1. **{最弱维度}**（{X}/5）：{具体问题} → {改进建议}
2. **{次弱维度}**（{X}/5）：{具体问题} → {改进建议}

### 下一步建议

{根据判断给出动作建议}
```

注意：第 5 维度名称因品类而异：
- 短篇 → "30% 试读卡点"
- 连载 → "追更粘性"

### Step 4: 判断与建议

| 总分 | 判断 | 建议 |
|------|------|------|
| >= 30 | 强题 | "强题。建议直接跑 /predict 进入正式预测。" |
| 25-29 | 可做 | "可做。建议先补强 {薄弱维度}，再跑 /predict。" |
| 20-24 | 弱题 | "弱题。存入灵感池等待改造，当前不建议立项。" |
| < 20 | 放弃 | "放弃。核心卖点不成立，建议换方向。" |

---

## 边界 & 拒绝

- **不写文件**：不创建 prediction 文件、不更新 state、不写 candidates.md
- **不预测收入**：收入 bucket 是 `/novel-predict` 的工作，本 skill 只做维度评分
- **不做代笔**：不帮用户补全大纲、不写开头、不改稿
- **不接受后验打分**："这本已经发了追更数据是 X%，帮我打分" → 拒绝。已有数据的走 `/novel-retro`
- **信息严重不足时**：如果用户只给一句话（如"写个修仙的"），不强行打分，而是追问："至少告诉我：标题（哪怕暂定）、核心冲突、主角卖点，我才能给出有参考价值的分数。"
