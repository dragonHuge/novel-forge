# 观察生命周期（Observation Lifecycle）

> 从复盘中发现规律，经验证后沉淀为正式评分维度——这是 rubric 进化的唯一合法路径。

---

## 流转全景

```
复盘发现
  │
  ▼
观察区（待验证）── rubric_notes.md 的 "## 观察区" 段
  │
  │ 多次验证（≥3 次独立复盘支持）
  ▼
规律沉淀区 ── rubric_notes.md 的 "## 规律沉淀区" 段
  │
  │ bump 时决策
  ├──→ 吸收为正式维度（写入 rubric 定义）
  └──→ 删除（证伪或不再适用）
```

---

## 阶段定义

### 1. 复盘发现

**来源**：每次执行 `/retro`（数据复盘）时，对比预测与实际表现，发现的偏差模式。

**形态**：一句话观察 + 证据来源

示例：
```
- 开篇 3 段内出现强冲突的作品，完读率普遍高于无冲突开篇（来自：《末世囤货》复盘）
```

**写入位置**：直接追加到 `rubric_notes.md` 的 `## 观察区`。

---

### 2. 观察区（待验证）

**状态**：假说阶段。已被提出但尚未被多次独立验证。

**格式**：

```markdown
## 观察区

### [观察标题]
- 描述：一句话概括规律
- 首次发现：YYYY-MM-DD，来自《作品名》复盘
- 支持证据：
  - YYYY-MM-DD《作品A》：具体数据佐证
- 反对证据：
  - （暂无）
- 验证次数：1/3
```

**规则**：
- 每次复盘如果发现与已有观察相关的证据，追加到对应观察的"支持/反对证据"下
- 不要修改观察的原始描述（保持首次提出时的表述）
- 支持证据来自不同作品才计为独立验证

---

### 3. 规律沉淀区

**晋升条件**：

- ≥ 3 次**独立**复盘支持（来自不同作品）
- 无未解释的反对证据
- 观察可操作化（能转化为具体的评分维度或权重调整）

**格式**：

```markdown
## 规律沉淀区

### [规律标题]
- 描述：一句话概括
- 验证记录：3/3（列出来源作品）
- 可操作化方向：建议转为什么维度 / 调整什么权重
- 状态：待 bump 吸收
```

**规则**：
- 从观察区移到沉淀区时，保留完整的证据链
- 沉淀区的条目是 bump 的候选输入，但不自动生效

---

### 4. Bump 决策

**时机**：当 `rubric_notes.md` 的规律沉淀区积累了 3+ 条待处理条目，或 `calibration_samples` 达到阈值（如每增加 5 个样本触发一次 review）。

**决策选项**：

| 决策 | 含义 | 操作 |
|------|------|------|
| 吸收 | 转为正式维度或权重调整 | 写入 rubric 定义文件，从沉淀区删除 |
| 延迟 | 证据够但时机不对 | 保留在沉淀区，标注"延迟：原因" |
| 删除 | 证伪或不再适用 | 从沉淀区移除，移入 "## 已归档"（保留审计轨迹） |

**bump 流程概要**：

```
1. 汇总沉淀区所有待处理条目
2. 逐条评估：吸收 / 延迟 / 删除
3. 对要吸收的条目，设计具体的维度定义和权重
4. 用校准池（已有预测+复盘的作品）重新打分验证
5. 确认无退化后，正式写入 rubric
6. 更新 .novel-state.json 的 rubric_version 和 last_bump_at
```

---

## 反模式（禁止）

| 反模式 | 为什么禁止 |
|--------|-----------|
| 单次复盘直接修改 rubric | 孤证不立，可能是噪声 |
| 跳过观察区直接进沉淀区 | 缺少多次验证，容易过拟合单个案例 |
| 修改已有观察的原始描述 | 破坏审计轨迹，无法追溯思路演变 |
| 删除反对证据 | 确认偏误，必须保留完整证据链 |
| bump 时不重新打分验证 | 可能引入退化而不自知 |

## rubric_notes.md 模板

```markdown
# Rubric Notes

## 观察区

（复盘中发现的规律假说，待多次验证）

## 规律沉淀区

（经 ≥3 次独立验证的规律，待 bump 吸收）

## 已归档

（被证伪或不再适用的观察，保留审计轨迹）
```

## 与其他模块的关系

| 模块 | 与观察生命周期的关系 |
|------|---------------------|
| `/retro` 复盘 | 观察的唯一合法来源 |
| `/predict` 预测 | 使用当前 rubric（含已吸收的规律）打分 |
| `/bump` 升级 | 从沉淀区吸收为正式维度 |
| `session-start.sh` | 展示校准样本数（间接反映观察积累） |
| `prediction-immutability.sh` | 保护预测不被后见之明修改 |
